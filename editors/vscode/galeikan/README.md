# Galeikan Language for Visual Studio Code

Syntax highlighting and language configuration for `.gak` and `.gaks` files. Both extensions use the same Galeikan grammar and can be interpreted or compiled where the native backend supports the program.

The extension highlights declarations, imports, types, effects, calls, comments, strings, numbers, and operators. It also provides bracket matching, comment toggling, and indentation for blocks. The optional [Galeikan Eclipse](https://marketplace.visualstudio.com/items?itemName=galeikan.galeikan-eclipse) theme is a separate extension, so this language support works with your existing VS Code theme.

Install the release VSIX with **Extensions: Install from VSIX…** in Visual Studio Code, or use the Marketplace listing. The extension does not run code or start background services. The [guide](https://github.com/GaleikanOrg/Galeikan/blob/main/docs/quickstart.md) and [technical reference](https://github.com/GaleikanOrg/Galeikan/blob/main/docs/technical.md) document the current language.
