# Galeikan for Visual Studio Code

Syntax highlighting and language configuration for `.gak` and `.gaks` files. Both extensions use the same Galeikan grammar and can be interpreted or compiled where the native backend supports the program.

The extension highlights declarations, imports, types, effects, calls, comments, strings, numbers, and operators. It also provides bracket matching, comment toggling, and indentation for blocks. The optional **Galeikan Eclipse** theme uses a near-black surface and ice-blue accents matching the Galeikan website.

Install the release VSIX with **Extensions: Install from VSIX…** in Visual Studio Code. The extension does not run code or start background services.
